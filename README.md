# Flipkart Login GUI

A simple Flipkart-style login interface built using Python's Tkinter library, featuring a styled form with the Flipkart logo and basic email/password validation.

## Features

- Clean, styled login form UI
- Flipkart branding (logo used as both window icon and header image)
- Basic login validation with success/error popups

## Tech Used

- Python 3
- Tkinter (GUI)
- Pillow (image handling)

## How to Run

```bash
pip install pillow
python login_app.py
```
